Project for the Course AI Programming with Python - module PCEP Certification Prep

Project: A Data-Driven Approach to AI and Python

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook
```

Open `Udacity - PCEP Project.ipynb` in Jupyter and run the cells.
